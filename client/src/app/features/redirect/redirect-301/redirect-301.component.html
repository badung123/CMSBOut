301 các domain về domain cuối bằng Cloudflare Page Rule

Page rule giữ đúng host đã nhập: www.domain/*, subdomain.domain/* hoặc domain/*. Forwarding URL, mã 301, đích https://domain-cuối/$1. Tài khoản Cloudflare ở pageRule cần chứa đúng host đó, hoặc domain cha nếu host là www hay subdomain. Tài khoản đang bật thì tạo hoặc sửa rule; tài khoản tắt thì Disable rule đó.
